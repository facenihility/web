调度模型说明页面内置 v1 标定版

cost(task,node) = 1.00·(L_est / D) + 0.70·E_node + 0.30·U_node + 0.35·O_work + 3.0·max(0, L_est/D − 1)
node* = arg min [ cost + 0.20 × 在途连接数 ]
L_est = 路径时延 + 传输时延 + 排队时延 + 计算时延（广域/回传链路另计时延抖动余量）；D 为任务截止时延；E_node 为节点综合能耗系数（含 PUE 与制冷）；U_node 为节点负载率；O_work 为算力占用度。预估时延超出截止时延的部分按 3.0 倍线性放大作为违约惩罚，逼使调度器规避不可行节点。
负载平准：择优时叠加 0.20 × 在途连接数。两个边缘节点物理对称时，仅比代价会退化为近似随机选择（违约惩罚数值巨大却几乎相等，把负载信号淹没）；加入平准项后对称节点自动交替承接，显著摊平拥塞。
算力分配：节点算力按 优先级^1.35 × 截止紧迫度 加权推进；现场算力一体机预留 60% 算力专供实时控制任务（机器人），保障控制回路不被大流量任务挤占。静态基线仅按优先级均分。
带宽分配（拥塞自适应）：遵循「非必要不干预」——链路利用率 ≤95% 时保持等权公平共享（公平共享在非拥塞网络下平均完成时间最优，此时差异化只会制造输家）；越过 95% 拥塞门限后线性渐入 prio^1.3 加权，把带宽优先让给时延敏感任务。倾斜刻意保持轻度：更强的倾斜会在饱和期显著推高平均时延，却换不回短任务的截止达成。分配保持工作保持特性，空闲带宽被活跃流充分复用。
对照基线：静态规则映射（机器人→本地；视觉 / AGV / 维护→边缘；大模型→云端）+ 等权均分带宽，不感知实时负载、拥塞程度与截止时延。
离线 / 在线说明：本页离线运行时使用页面内置引擎（v1 标定版），与页面自带测试基线完全一致；连接后端后，由后端模型接管（默认 v2 优化版：流体排队修正 + 通算权衡「拥塞时降采样上传，用算力换带宽」），可在上方「模型与实验」卡片中切换与对照。
